# Use a furniture rig with browser-driven adjustments

The desk, monitor arm, and ergonomic chair will be built as one reproducible Blender furniture rig with named moving assemblies, while browser code continues to derive their fitted positions from the current measurements. Keeping the existing procedural Three.js furniture would be lighter but cannot reach the required form and material quality; baking fixed furniture poses into the GLB would prevent the scene from following height and calibration changes.
