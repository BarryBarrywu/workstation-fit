# Share the fit core across platform editions

The website and Xiaohongshu mini tool will live in the same repository with separate presentation and build entry points: the mini tool is isolated under `apps/xhs-mini-tool/` while both may import stable fit calculations and evidence-status rules from the shared domain core. Copying formulas or source data into a platform-specific implementation is rejected because independently published tools must not drift numerically, but sharing domain code never authorizes one platform's presentation, first-visit state, storage behavior, tests, or release work to change the other. Platform-specific adapters own those differences. Platform releases move independently and each published build identifies its fit-model version and source-verification date; a website release does not wait for Xiaohongshu review, while a materially incorrect platform build must be paused or replaced. Each platform owns an isolated local fit profile, with no synchronization or transfer path, and generated upload archives are not repository source.
