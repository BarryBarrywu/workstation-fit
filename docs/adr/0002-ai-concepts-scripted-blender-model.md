# Use AI concepts and a scripted Blender model

AI-generated images will establish the robot's original visual direction, but the production GLB will be built from a reproducible Blender scene and Python script. Production generation and export run through Blender's headless CLI so the same command can recreate the assets without a live GUI or MCP session. The repository will retain the editable `.blend`, the reproducible Blender Python script, and the web-ready `.glb` as separate asset layers. Direct image-to-3D output was rejected as the primary asset because its topology, rigid-part separation, joint hierarchy, and node naming are not predictable enough for measurement-driven fit poses. A live Blender bridge or MCP may be added later for interactive art direction, but it is not part of the reproducible build path.
